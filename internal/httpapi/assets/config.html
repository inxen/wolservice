                Linux 普通用户如何免密关机？
                
SSH 登录用户通常是普通用户，sudo 在非交互会话中不能询问密码，必须配置 NOPASSWD。以下配置需在目标主机上完成，并把 wol 换成实际的 SSH 登录用户。

                
# 目标主机：/usr/local/sbin/wol-shutdown
#!/bin/sh
exec /sbin/shutdown -h now

                
# 目标主机：/etc/sudoers.d/wol
wol ALL=(root) NOPASSWD: /usr/local/sbin/wol-shutdown
# sudo chmod 0755 /usr/local/sbin/wol-shutdown
# sudo chmod 0440 /etc/sudoers.d/wol

                
保存后点上方「Linux · 辅助脚本」，或手动填写 sudo -n /usr/local/sbin/wol-shutdown。

                
sudo -S 密码管道：「Linux · sudo 密码」会填入 echo '你的密码' | sudo -S systemctl poweroff。密码会出现在命令行进程参数和配置文件中，建议仅临时使用；长期运行优先用 NOPASSWD 或辅助脚本。
